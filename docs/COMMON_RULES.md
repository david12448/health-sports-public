# Common Rules Reference

Canonical repository: https://github.com/david12448/project-common-rules (private).

The central repository currently contains only a README title; until canonical policies are published, apply the user-provided baseline:
1. Separate public normalized data from private raw collection data, logic, and databases; reduce bulk copying risk.
2. Record failures, causes, fixes, and verification in Markdown.
3. Preserve working features; validate significant changes and use pull requests.
4. Do not create recurring project progress notifications.

Future updates must be reviewed for conflicts and synchronized via PR; do not automatically overwrite local policy.
